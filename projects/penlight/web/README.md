# 应援棒 · 手机端（@linjie/penlight-web）

晚会中场的互动游戏：观众把手机当应援棒，跟着音乐挥动，手机判定节奏稳不稳。
这里是第一阶段的**单机版**，用来验证挥动检测和判定手感。需求见 [`docs/brief.md`](../docs/brief.md)。

## 本地开发

```bash
pnpm install
pnpm penlight dev    # http://localhost:5173，电脑上用「点屏幕」模式调试，空格键也能打拍
pnpm penlight dev:https # 局域网 HTTPS（自签名证书），手机连同一个 Wi-Fi 访问终端里打印的地址
```

传感器 API 只在 HTTPS 页面、而且不被 iframe 嵌套时才有数据。手机访问 `dev:https` 的地址时会提示证书不受信任，
选择继续访问即可。也可以直接用 GitHub Pages 上的部署版本测试。

## 页面流程

1. **首页**：填 QQ 昵称（可不填），点「检测传感器」。iOS 会在这一步弹出传感器授权。
2. **传感器自检**：实时曲线（优先用陀螺仪）、分方向的挥动计数、5 档灵敏度。
   2 秒没有数据会列出可能的原因，并提供「点屏幕」模式。
3. **选歌**：内置测试曲（160 BPM、46 秒，拍点精确已知），或者上传歌曲。
4. **选段和节拍**（上传歌曲才有）：
   - 选片段：边听边点「设为开头 / 设为结尾」，或者拖波形两头的圆点，都会对齐到小节线；
     点开起止时间可以按小节前后微调；另有「推荐副歌」和「整首」。最短 20 秒，歌曲最长 6 分钟。
   - 速度：变速的歌按段显示 BPM，可以对某一段单独 ½ / ×2。
   - 拍子位置：±10 ms、指定小节第一拍、「跟着敲」手动标拍子。
   - 对拍试听：波形随播放滚动，叠加节拍器（小节第一拍音高更高），可以听片段的开头、中段、结尾。
5. **游戏**：整屏是应援棒颜色，按段落换色。预备 4 拍倒数 → 8 拍热身（不计分）→ 正式计分。
   每次挥动闪一下白光，命中闪得更亮；中间大数字是近 8 下稳定度。
6. **结果**：总分、同步率、参与度、平均偏差、乱挥次数、每小节的打法变化、偏差分布和计分明细。
   还可以导出本局的传感器原始数据，用来调参数。

检测和计分的规则见 [`docs/judging.md`](../docs/judging.md)。

## 代码结构

```
src/
  screens/       每个页面一个组件
  components/    通用组件（按钮、卡片、分段控件、曲线和图表）
  game/          一局游戏的运行：音频播放、输入、交给 Judge 判定
  lib/           传感器、音频、节拍识别、测试曲合成等不依赖 React 的模块
  workers/       节拍识别的 Web Worker（Essentia.js）
  styles/        设计 token 和全局样式
```

判定和计分都在 [`@linjie/penlight-core`](../core) 里，这里只负责采集输入和展示。

- 挥动检测：`SwingDetector`，找挥动的转向点并区分方向。优先用陀螺仪（`rotationRate`），
  没有时用加速度（`acceleration`，拿不到再对 `accelerationIncludingGravity` 做高通）。
- 时间换算：`SongClock` 把事件时间戳换成歌曲时间，
  `ctx.currentTime − (performance.now() − event.timeStamp) / 1000 − outputLatency`，
  并持续采样两个时钟的差值去掉 `currentTime` 的跳变。
- 节拍识别：`RhythmExtractor2013`（multifeature）先分析前 90 秒，整首在后台接着分析，结果用 `buildBeatMap`
  整理成逐拍的节拍表，支持变速。结果按文件指纹缓存在 IndexedDB。

## 设计约定

- 颜色、字号、圆角、间距、动效时长都定义在 `src/styles/tokens.css`，组件里不写死数值。
  深色是默认主题，浅色跟随系统，也可以在首页右上角切换。
- 图标全部来自 `lucide-react`。
- 按 360 px 宽度设计，所有页面在这个宽度下不能横向溢出。
- 动效用 `motion`，尊重系统的「减弱动态效果」设置。游戏中的闪光和进度条直接操作 DOM，不走 React 渲染。
- 字体随包发布（Geist / Geist Mono），不依赖 Google Fonts，校园网里也能正常加载。

## 阶段 1 验收清单

- [ ] 传感器自检页：iPhone 和 Android 各至少 2 台都能看到实时加速度曲线
- [ ] 挥动检测：正常挥 20 下，识别次数误差在 ±1 以内；拿着手机走路不误触发
- [ ] 内置测试曲跑完整局，结果页各项数据正确
- [ ] 上传真歌：自动识别 BPM 和第一拍，试听时节拍器与鼓点听感对齐，½ / ×2 / 微调可用
- [ ] 点屏幕降级模式可用，桌面浏览器也能调试
